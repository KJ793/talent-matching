# Intelligent Talent Matching Platform

A web application for matching job seekers with employers, built for CSIT314.

## Tech stack

- PHP 8.x (no framework, procedural with light OOP)
- MySQL 8
- Vanilla HTML/CSS/JavaScript (no build step)

## Project structure

```
.            — Web-accessible PHP entry points
src/         — Application classes (repositories, helpers)
config/      — Configuration files
database/    — SQL schema and seed data
docs/        — Project documentation
```
